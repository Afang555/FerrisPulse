```markdown
⚡【FerrisPulse · 灵脉 2.0】跨品牌外设调度与独占感知引擎
本项目为原《雷蛇电量管家》重构升级版本。采用纯原生 C# 5.0 / Win32 API 编写，无第三方运行库依赖，单文件绿色运行。旨在替代常驻多进程、占用近 1GB 内存的官方驱动全家桶，提供跨品牌外设电量直读与硬件级 8000Hz 场景动态调度。

（便携包下载见 Releases，绿色单文件解压即用）

---

🛠️【核心技术实现与性能实测】

1. 内存与资源开销实测
• 官方驱动（Synapse 3 / G HUB 等）：常驻 8~10 个后台守护服务，内存占用 500MB~1000MB+，定期唤醒 CPU。
• FerrisPulse 2.0：单进程单文件，常驻内存仅 ~12.8MB（开销较官方降低 98%），CPU 占用稳定 0.00%，零开机自启常驻服务。

2. 跨品牌硬件 HID 私有协议直连
• 雷蛇 (Razer)：解构专有 90 字节双向 Feature Report 协议，直连 2.4G 接收器与有线通道，毫秒级读取电量并下发回报率切换指令。
• 罗技 (Logitech)：自研原生 HID++ 1.0 / 2.0+ 协议引擎，免官方驱动直接握手 Lightspeed 与优联通道，读取精准电量与固件全称。
• 努斐 (NuPhy) & 国产方案：直连客制化键盘休眠超时调节、WinLock 物理级锁键；原生适配 CompX 方案（ATK、VGN、迈从、狼蛛等）。

3. 游戏前台独占感知与 8000Hz 动态调度
• 场景仲裁：日常桌面 1000Hz 节能；前台检测到 CS2、无畏契约、Apex 等游戏独占全屏时，毫秒级直切 4000Hz / 8000Hz 满血模式，切回桌面平滑降频。
• 反作弊安全保证：完全基于 Win32 标准 GetForegroundWindow / 窗口几何检测，零内存读写、零 DLL 注入、零 API Hook，100% 反作弊安全。
• 战术 OSD 浮窗：基于 Win32 扩展样式 WS_EX_TRANSPARENT 与 SWP_NOACTIVATE 实现鼠标物理穿透与零焦点置顶，全屏激战调节 DPI / 回报率不抢焦点、不吞枪。

4. 原生 GDI+ 拟态渲染与 SWR 原子更新
• 任务栏自绘：提供胶囊进度、拟真微标、极简纯净数字三种托盘风格，支持平滑充电流光动画与休眠感知。
• 架构基建：采用 Stale-While-Revalidate 静默自检，支持 GitHub / Gitee 国内外双活节点测速，下载后原子进程原地热替换自重启。

---

💻【运行环境与构建说明】
• 运行环境：Windows 10 / 11 64位（原生自带环境，无需安装任何依赖）
• 源码构建：基于 Windows 自带 csc.exe（C# 5.0 / .NET 4.0 语法基准），仓库内执行 build.bat 即可一键生成单文件二进制。
• 欢迎开发者在 GitHub / Gitee 提交 Issue 反馈外设 VID/PID，共同丰富设备协议库。
```
