# 玄熊猫鼠标使用指南

当前入口以“按应用切换设置”为主：FerrisPulse 识别前台应用的完整 exe 路径，为指定玄熊猫 HID 端点切换已有 DPI 档位与回报率。

## 支持范围

- 当前识别 VID `3554`、无线接收器 PID `F5A9` 与有线 PID `F5AB` 的已知协议端点。相同型号的其他实物不按某一只鼠标的序列号绑定；每个 HID 端点保留独立身份。
- 电量来自设备实际回复；读取失败时保持未知，不填入模拟百分比。
- DPI 档位表来自鼠标实际内存。仅切换已有档位，不能新增、删除或编辑档位数值。高 DPI 扩展编码尚未验证，无法可靠解码时显示未知并停止相应自动切换。
- 回报率仅提供 `125 Hz` 与 `1000 Hz`，不支持 `4000 Hz`。
- 当前无线实机验证包含 `85%` 电量读取、`800/1600 DPI` 档位与 `125/1000 Hz` 的实际写入及回读。有线端点已有抓包依据，尚不能据此宣称有线实机写入验证完成。界面多只同型号设备的实物操作也未完成验证。

## 设置应用规则

1. 先退出官方 **Mouse Drive Beta**，避免两个程序同时通信。连接鼠标，运行本地构建目录中的 `FerrisPulse.exe`；程序常驻系统托盘。
2. 右键托盘图标，点击菜单顶部的 **玄熊猫 · 按应用设置…**。
3. 点击 **添加应用…**，浏览并选择实际进入前台的 `.exe` 文件。已有规则可选中后点击 **浏览 exe…** 更换路径。按完整路径匹配，大小写不影响匹配；快捷方式、启动器与游戏本体通常是不同目标。
4. 选择 **目标设备端点**。对照窗口下方的设备名称与端点 ID，确认目标。无线和有线连接是不同端点；端点变化后需要重新选择，程序不会转绑到任意一只同型号鼠标。
5. 填写从 `1` 开始的 **DPI 档位**，并选择 `125` 或 `1000` Hz。档位号不是 DPI 数值：当前已验证样机的档位 1 为 `800 DPI`、档位 2 为 `1600 DPI`，其他鼠标以实际读取到的档位值为准，可在规则窗口底部或主界面核对。
6. 勾选 **启用**，点击 **保存**。同一应用和同一设备端点只保留一条规则；同一应用可为不同端点分别保存规则。
7. 切到目标应用并保持前台约一秒，等待设置应用。回到没有匹配规则的应用时，恢复首次进入规则前的 DPI 档位与回报率；从规则 A 切到规则 B 时保留同一份进入前快照。

规则保存在 `%LocalAppData%\FerrisPulse\application-profiles.xml`。打开规则窗口时自动调度暂停，保存或取消后继续；编辑窗口本身不发送硬件命令。

## 没有切换时

确认实际前台程序与规则的完整 exe 路径一致、目标端点仍连接、当前档位表和回报率均已读到。无法读取前台路径时暂时保留当前规则状态，避免误判退出。写入需收到匹配回复并回读确认；失败后会在后续调度重试。

应用规则生效期间优先于旧的游戏自动设置，避免重复改写。正常退出 FerrisPulse 时会尝试恢复仍连接设备的进入前设置；断连、通信失败或强制结束进程不能保证恢复。重新连接若产生新的端点 ID，应打开规则窗口重新选择，不会自动套用旧端点规则。
