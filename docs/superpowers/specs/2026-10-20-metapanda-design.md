# 玄熊猫同系列鼠标适配设计

日期：2026-10-20

## 目标与已确认范围
基于 FerrisPulse 保留原有托盘、电量、其他品牌设备及游戏调度功能，新增玄熊猫同款鼠标的有线与 2.4G 控制，以及按应用自动切换 DPI 和回报率。用户当前要求不做 4K。

## 证据
本机抓包确认 VID 3554，1K 接收器 PID F5A9，有线 PID F5AB。接口使用 Report ID 08 的 17 字节 Output Report，控制经 SET_REPORT、interface 1，响应经输入报告。命令 07、参数地址 0004 切换 DPI 档位 0/1；地址 0000 切换回报率，值 01=1000Hz、08=125Hz。命令 04 查询电量，返回字节 6 为百分比，字节 7 为充电状态。只把这些当作已观察证据，直接控制仍须硬件验证。

## 兼容与识别
不绑定鼠标序列号，支持其他相同型号设备。设备逐只枚举，以 HID 路径区分同时连接的鼠标；已知 PID 结合接口能力和响应验证后启用控制。同厂 VID 不能单独证明兼容。其他玄熊猫型号通过产品名称、设备能力与同协议响应识别；未验证型号保留识别信息，不能自动发送设置命令。支持新增型号描述，不宣称全系列已经验证。

## 通信与状态
独立 Metapanda 模块，复用公开 Win32 HID 声明。对每个设备串行通信，设置有超时、响应命令与校验验证；失败不把 UI 当作成功。优先读取实际 DPI 档位、当前档位及回报率。无法可靠读取则显示未知，并禁止依赖未知值的自动切换，不伪造 1600/1000 等默认状态。800/1600 通过匹配实际档位实现，不改变整张 DPI 表。当前控制仅允许 125/1000Hz，4K 待另行验证。

## 应用规则（实现选择，待用户审阅）
新增可编辑规则：应用 exe 完整路径、目标设备、目标 DPI 档位/数值与目标回报率，规则可禁用。前台应用匹配完整路径，窗口切换防抖；用户选择的规则优先于既有游戏调度，无匹配时恢复该设备的桌面设置。保留原来的游戏/桌面机制，无应用规则时维持原行为。设置不变时不重复发送；设备断开时停止发送，重连后重查能力。规则本地持久化，界面支持添加/删除应用与修改设置。

## 非目标与边界
不修改官方软件文件，不写固件，不控制 4K/蓝牙。不同型号的具体协议差异须后续设备验证。保留 C# 5、.NET Framework 4.0、零第三方运行依赖和 UTF-8 BOM。用户指定 D:\data\github\mose 为工作目录，优先于上游旧目录约束。

## 验证与交付
离线测试覆盖真实抓包报文、校验错误、错设备/错响应、断开及超时、规则匹配与恢复、重复设置抑制。原生 csc 构建及既有适当回归测试必须通过。硬件先执行只读查询，再在用户已授权的 800/1600、125/1000 范围内验证切换及恢复；有线与无线分别报告验证结果。多只设备没有实机时明确说明只完成隔离逻辑测试。提供本地源码、可执行程序和使用说明；不默认推送上游或发布。

## 审查后补充的实现选择
规则以单个连接端点绑定，不自动把有线与无线视为同一只物理鼠标。优先采用可用序列号加 VID/PID/接口能力建立持久标识；无唯一序列号时采用设备实例/路径标识，路径变化后规则待重新绑定，禁止猜测匹配同型号设备。有线和无线可以分别配置规则；对其他同款设备复用设置需用户显式选择目标。未知 PID 的只读协议探测须用户主动触发，不后台向未知设备发送私有命令。读回格式与 ACK 校验首先由已有抓包和只读查询建立证据；不能证明读取正确时不开放依赖该字段的自动控制。
